# Chess Console

A two-player, console-based chess game written in C++20.

## About

Focus on OOP and software dev. 
The goal is to implement a playable chess game with a class-based structure. 

## Setup

- C++20
- GCC
- CMake
- Git
- GitHub
- GitHub Actions

## Idea

If a figure is to be moved, compute all possible legal moves including rochade, king in check, en passant and then validate if said move is legal or not.
